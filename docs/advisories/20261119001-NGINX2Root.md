# NGINX2Root Active Exploitation - 20261119001

## Overview

The WASOC has observed critical vulnerabilities affecting NGINX products dubbed "NGINX2Root". Successful exploitation could allow a remote unauthenticated attacker to perform remote code execution.

## What is vulnerable?

| Products and Versions Affected | CVE | CVSS | Severity |
| ------------------------------ | --- | ---- | -------- |
| NGINX <br> - From 1.9.5 prior to 1.30.7 <br> - 1.31.x prior to 1.31.9 | [CVE-2026-123007](https://nvd.nist.gov/vuln/detail/cve-2026-123007) <br> [CVE-2026-123634](https://nvd.nist.gov/vuln/detail/cve-2026-123634) <br> [CVE-2026-123633](https://nvd.nist.gov/vuln/detail/cve-2026-123633) <br> [CVE-2026-121810](https://nvd.nist.gov/vuln/detail/cve-2026-121810) <br> [CVE-2026-113425](https://nvd.nist.gov/vuln/detail/cve-2026-113425) | 9.2 </br> 9.2 </br> 9.2 </br> 9.2 </br> 9.2 | **Critical** </br> **Critical** </br> **Critical** </br> **Critical** </br> **Critical** |

## What has been observed?

The WASOC has been made aware of exploitation in the wild for one or more of the mentioned vulnerabilities.
The WASOC has not received any reports of exploitation of this vulnerability on Western Australian Government networks at the time of writing.

## Recommendation

The WASOC recommends administrators apply the solutions as per vendor instructions to all affected devices within expected timeframes (refer [Patch Management](../guidelines/patch-management.md)):

- NGINX article: <https://nginx.org/en/CHANGES>
