# Oracle CA Trust Updates - 20261029002

## Overview

This Security update addresses CVE-2026-91403 by providing Java updates which distrusts the set of impacted intermediate CA certificates related to eMudhra. 


## What is vulnerable?

| Product(s) Affected | Version(s) | CVE                                                                                                                                      | CVSS         | Severity                                                       |
| ------------------- | ---------- | ---------------------------------------------------------------------------------------------------------------------------------------- | ------------ | -------------------------------------------------------------- |
| Oracle Java SE      | 8u511, <br/> 8u511-perf, <br/> 11.0.33, <br/> 17.0.21, <br/> 21.0.13, <br/> 25.0.5, <br/> 27.0.1   | [CVE-2026-91403](https://nvd.nist.gov/vuln/detail/cve-2026-91403)    |    9.1   | **Critical**    |

## What has been observed?

The WASOC has not received any reports of exploitation of this vulnerability on Western Australian Government networks at the time of writing.

## Recommendation

The WASOC recommends administrators apply the solutions as per vendor instructions to all affected devices within expected timeframes (refer [Patch Management](../guidelines/patch-management.md)):

- Oracle: <https://www.oracle.com/security-alerts/alert-cve-2026-91403.html>
