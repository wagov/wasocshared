# Cisco Nexus 9000 Series Switch Remote Code Execution Vulnerability - 20260904001

## Overview

The WASOC has been made aware of a vulnerability in Cisco Nexus 9000 Series Switches that could allow an unauthenticated, remote attacker to execute code with root privileges.

A successful exploit of the vulnerability in the Silicon One integration for Cisco Nexus 9000 Series Switches could allow an attacker to connect to an affected device and send crafted input that could be executed as code with root privileges. Cisco has released software updates that address this vulnerability and is urging affected organisations to apply the available patches.

## What has been observed?

The WASOC has not received any reports of exploitation of this vulnerability on Western Australian Government networks at the time of writing.
